**LoreFetch v0.1.0** turns an ordinary webcam into a Magic: The Gathering collection scanner. It runs fully offline, with no subscription and no phone.

## Download and run

1. Download `LoreFetch-v0.1.0-win-x64.zip` and unzip it anywhere.
2. Run `LoreFetch.exe`. Keep the `data` folder next to it, because that's where the card index lives.
3. The exe is unsigned, so Windows SmartScreen may warn you. Click **More info → Run anyway**.

Requirements: Windows 10/11 x64 and a USB webcam. It was built and tested with a Logitech C920. You don't need to install .NET.

## Setup that works

- Mount the camera about **15″ above the table**, looking straight down, in landscape (not rotated).
- Use a **light-coloured mat** or paper, and **leave a finger-width gap** between cards.
- Use diffuse light from the side. Glare is the main thing that breaks recognition.
- Scan 1, 3 or 9 cards at a time.

## Using it

| Key / action | Effect |
|---|---|
| **Space** | Capture the cards in view |
| **Enter** | Accept: add every tile that isn't crossed out to your collection |
| **Escape** | Discard the capture |
| **Left-click a tile** | Cross it out (exclude it) |
| **Right-click a tile** | Set the card by hand, or clear your choice |

Auto mode captures by itself once the expected number of cards has been still for half a second.

Your collection is saved as a CSV at `Documents\LoreFetch\collection.csv`, and it can be exported for **Moxfield** import.

## Limitations in v0.1.0

- **Oracle name only.** Reprints that share artwork can't be told apart, so there's no set, printing or price.
- Modern-frame (2015+), English, non-foil, single-faced cards only.
- Cards from sets released after this index was built (September 2026) won't be recognised until a new release.
- Cards that touch edge-to-edge in a line merge into one and aren't detected, so leave gaps.
- Black mats are harder than light ones.
