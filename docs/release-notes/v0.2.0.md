**LoreFetch v0.2.0** organises scanning into runs, makes the capture grid easier to check, and fixes setting a card by hand.

## Download and run

1. Download `LoreFetch-v0.2.0-win-x64.zip` and unzip it anywhere.
2. Run `LoreFetch.exe`. Keep the `data` folder next to it, because that's where the card index lives.
3. The exe is unsigned, so Windows SmartScreen may warn you. Click **More info → Run anyway**.

Requirements: Windows 10/11 x64 and a USB webcam. You don't need to install .NET.

## What's new

- **Runs.** Each launch starts a new, empty run: one CSV per scanning batch, saved to `Documents\LoreFetch\Runs\` from the first Enter. The **File** menu starts a new run, opens or renames an earlier one, shows it in its folder, and exports it as a native CSV or a Moxfield upload.
- **Capture grid.** Captures show as a 3×3 grid with each card's name above it, so you can read it against the printed title. Drag the divider to give the tiles more room.
- **Steadier outlines.** Card borders in the live preview hold still instead of jittering and flickering.
- **Setting a card by hand** works properly. The type-ahead ignores capitals and lists names that start with what you typed first. Arrow keys move the highlight, and Enter picks. While you're setting a card, auto mode won't replace the grid.
- **The exe knows its version.** Right-click `LoreFetch.exe` → **Properties → Details** shows it. Please include it in bug reports.

## Upgrading from v0.1.0

- Your v0.1.0 collection at `Documents\LoreFetch\collection.csv` is left as it is. v0.2.0 doesn't open it at startup; use **File → Open…** to continue it.
- Export is now under **File → Export**. The export sidebar is gone.

## Limitations

Unchanged from v0.1.0, and so is the card index:

- **Oracle name only.** Reprints that share artwork can't be told apart, so there's no set, printing or price.
- Modern-frame (2015+), English, non-foil, single-faced cards only.
- Cards from sets released after the index was built (September 2026) aren't recognised.
- Leave a finger-width gap between cards. Black mats are harder than light ones.
